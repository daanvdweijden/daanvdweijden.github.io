Our poster on a typology of user engagement in conversational agent voting
advice applications received an honorable mention at the ACM Conference on
Conversational User Interfaces. [Read the paper](/pubs/2026-cavaa-engagement-typology/).

In this work we tried to create a user typology for CAVAA users, as they might differ from the type of users you find in regular voting advice applicatinos. Interestingly we find that although some groups overlap with existing typologies, there seems to be a new group emerging, that aims to test out the capabilities of the LLM underneath the system, rather than use the tool for its intended purposes.

This short paper is a first step towards this typology, but I feel like there is much more to find in this domain than we were able to do thus far. More coming soon!
